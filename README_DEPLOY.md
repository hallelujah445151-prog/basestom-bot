## Как деплоить на сервер:

### Автоматический деплой (рекомендуется):

**Windows:**
```powershell
cd C:\Users\crush\AppData\Roaming\projects\basestom
.\quick-deploy.bat
```

**Что делает этот скрипт:**
1. Создает ZIP архив с необходимыми файлами
2. Загружает архив на сервер (IP: 31.129.99.125)
3. Распаковывает архив на сервере
4. Устанавливает зависимости
5. Перезапускает бота через Supervisor
6. Показывает статус бота

### Ручной деплой (если автоматический не работает):

См. файл `MANUAL_DEPLOY.md` для детальных инструкций.

## Проверка после деплоя:

1. **Откройте Telegram**
2. **Найдите бота:** @sfdtgafvdba_bot
3. **Напишите:** `/start`
4. **Попробуйте создать заказ:** "Плюхин металлокерамика 2шт пациент Иванов"

## Управление ботом на сервере:

```bash
# Подключение к серверу
ssh root@31.129.99.125

# Проверка статуса
supervisorctl status basestom-bot

# Перезапуск
supervisorctl restart basestom-bot

# Просмотр логов
supervisorctl tail -f basestom-bot

# Выход из сервера
exit
```

## Возможные проблемы:

### 1. Бот не отвечает после деплоя:

**Решение:**
```bash
ssh root@31.129.99.125
supervisorctl status basestom-bot
supervisorctl tail -f basestom-bot
```

### 2. ИИ обработка не работает:

**Решение:**
- Проверьте файл `.env` на сервере: `/opt/basestom-bot/src/.env`
- Убедитесь, что API ключ OpenRouter действительный

### 3. Пользователи не находятся:

**Решение:**
- Проверьте базу данных: `/opt/basestom-bot/data/orders.db`
- Убедитесь, что пользователи существуют
